# Gray IP + AXI DMA source

Source snapshot for the independent Vivado 2025.2 `xc7z020clg484-2` gray DMA project. `rebuild_bd.tcl` and `ip_repo/bgr2gray_axis/` contain the BD topology and packaged custom RTL. AMD catalog IP is generated by Vivado. The original project was implemented and exported as a `TEST_ONLY` bit/hwh/XSA set; its creation-time README explicitly says no board test was performed then. Later board validation of a gray DMA Overlay is a separate evidence item and must be tied to artifact hashes before claiming binary identity.

The BD uses `axi_dma_0`, AXI-Lite `0x40400000`, Simple Mode, SG and Micro DMA disabled, MM2S BGRX32, S2MM Gray8, DRE on both channels, 26-bit transfer length. GP0 controls the IP; HP0 accesses DDR. FCLK0 runs the gray path at 50 MHz. DMA status is polled; interrupts are not routed to PS. The gray RTL carries one `TLAST` per whole frame.

The archived independent implementation reported WNS +10.559 ns, TNS 0, 2,626 LUT, 3,544 FF, 2 BRAM tiles and 3 DSP48E1 for the *whole system*. Its DRC had 0 error/critical warnings but included reset-path warnings. See `reference/` for original address and PS notes. This public source snapshot is not a bit-identical rebuild claim.

To reconstruct the BD in a new empty directory, run `vivado -mode batch -source rebuild_gray_project.tcl -tclargs <new_absolute_folder>`. The wrapper registers `ip_repo`, sources `rebuild_bd.tcl`, generates the BD wrapper and runs Validate. It does not run synthesis/implementation or export a bitstream. `rebuild_bd.tcl` refuses the wrong Vivado version. Do not source it into a project containing an existing `system` BD.
